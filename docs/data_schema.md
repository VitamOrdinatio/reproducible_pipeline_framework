# Data Schema  
## reproducible_pipeline_framework v2

---

## 1. Purpose

This document describes the structure of key tabular outputs generated by the
pipeline.

It serves as a data dictionary to:

- document expected columns
- clarify semantic meaning of fields
- support downstream analysis
- ensure reproducibility

This document complements:

- `state_contract_v2.md` (which documents runtime state)
- `SOP_pipeline_example.md` (which documents process)
- `workflow.md` (which documents execution flow)

---

## 2. Annotated Variant Table

File:

```
data/processed/annotated_variants.tsv
```

This table contains one row per variant and represents the fully annotated,
unfiltered variant set.

### Required Columns

| Column | Description |
|------|------------|
| chrom | Chromosome |
| pos | Genomic position |
| ref | Reference allele |
| alt | Alternate allele |
| gene | Gene symbol |
| consequence | Functional consequence |
| variant_type | coding or non-coding |
| AF_gnomAD | Allele frequency in gnomAD |
| AF_ExAC | Allele frequency in ExAC |
| AF_1KGenomes | Allele frequency in 1000 Genomes |
| ClinVar_classification | Clinical classification |
| AlphaMissense_score | Predicted pathogenicity (missense only) |
| SpliceAI_score | Splice impact score |

## 3. Filtered Variant Table

File:

```
results/runs/<run_id>/final/filtered_variants.tsv
```

This table contains variants retained after global filtering.

### Required Columns

All columns from the annotated table plus:

| Column | Description |
|------|------------|
| filter_status | Pass/fail status |
| filter_reason | Reason for removal if filtered |

---

## 4. Coding Track Table

File:

```
results/runs/<run_id>/final/coding_variants.tsv
```

Contains only coding variants.

### Required Columns

All annotated columns plus:

| Column | Description |
|------|------------|
| coding_interpretation | Preliminary coding-track interpretation |
| coding_priority | Ranking or priority tier |

---

## 5. Non-Coding Track Table

File:

```
results/runs/<run_id>/final/noncoding_variants.tsv
```

Contains only non-coding variants.

### Required Columns

All annotated columns plus:

| Column | Description |
|------|------------|
| noncoding_interpretation | Preliminary non-coding interpretation |
| noncoding_priority | Ranking or priority tier |

---

## 6. Prioritized Variant Table

File:

```
results/runs/<run_id>/final/prioritized_variants.tsv
```

Unified ranking across coding and non-coding tracks.

### Required Columns

| Column | Description |
|------|------------|
| gene | Gene symbol |
| chrom | Chromosome |
| pos | Position |
| ref | Reference allele |
| alt | Alternate allele |
| track | coding or non-coding |
| priority_score | Composite ranking score |
| priority_class | High / Medium / Low |

---

## 7. Validation Candidates Table

File:

```
results/runs/<run_id>/validation/igv_review_candidates.tsv
```

Used for optional manual IGV review.

### Required Columns

| Column | Description |
|------|------------|
| gene | Gene symbol |
| chrom | Chromosome |
| pos | Position |
| ref | Reference allele |
| alt | Alternate allele |
| reason_for_review | Reason flagged for review |

---

## 8. Summary Table

File:

```
results/runs/<run_id>/reports/prioritized_variants_summary.tsv
```

A compact table summarizing key results.

### Required Columns

| Column | Description |
|------|------------|
| metric | Summary metric name |
| value | Value of the metric |
